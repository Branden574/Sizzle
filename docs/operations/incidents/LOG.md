## Incident 2026-08-10 07:47 PDT — watchdog summon: API + frontend "unreachable" → FALSE ALARM (transient local DNS)

**What fired.** Watchdog (`scripts/ops/watchdog.sh`) summoned an unattended session at 2026-08-10 07:47:12 local reporting `API unreachable (HTTP 000)` and `Frontend https://getsizzle.app HTTP 000000`. Raw /health capture was `curl: (6) Could not resolve host: sizzle-chi.vercel.app`.

**Root cause (verified, not the symptom).** A transient **DNS/network failure on the watchdog host itself** at the moment of the 07:47 probe — *not* a production outage. Evidence for host-side, not origin-side: (1) the API failure was `curl (6) could not resolve host` — a resolver failure, whereas a Vercel origin outage would still resolve DNS and return 5xx from the edge; (2) both independently-deployed Vercel projects (API `sizzle` + frontend `sizzle-api`) failed *simultaneously* at the connection layer (`000`/unresolved), the fingerprint of a single shared client-side network drop rather than two separate origins dying in the same second; (3) `watchdog.sh` itself anticipates this exact class ("a summon that dies on a transient network error e.g. right after Mac wake"). Most likely a momentary resolver hiccup coinciding with the 5-min launchd tick / Mac wake.

**Production was never actually down.** On probe (~3 min after detection) both surfaces were fully healthy and stayed healthy across a spaced recovery window:
- API `/health` → **HTTP 200**, body `{"status":"ok","problems":[],"commit":"a42806c",...}` — `stuckVideoBacklog` 0, `cloudflareConfigured` true, `push` ok, `paymentsKeyMode` live, email/Sentry/moderation configured. `commit` = current HEAD `a42806c`, so **no rogue deploy** went out around the alert time.
- Frontend `getsizzle.app` → **HTTP 200**.
- Spaced confirmations (anti-flap): 14:49 UTC api=200 web=200 (dns 0.186s); 14:50 UTC health `status:ok` problems `[]`; 14:52 UTC api=200 web=200 (dns 0.009s/0.004s). No flapping; DNS lookup time fell from 0.186s→0.009s as the resolver cache re-warmed — consistent with a just-cleared momentary resolver failure.
